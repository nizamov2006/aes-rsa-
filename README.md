# AES + RSA · Кешенді қорғау

GitHub Pages арқылы жарияланатын, телефонның басты экранына орнатылатын веб-қосымша (PWA).

## GitHub-қа жүктеу

1. ZIP архивін ашып, ішіндегі файлдарды шығарыңыз.
2. GitHub-та `aes-rsa-app` деген ашық репозиторий жасаңыз.
3. **Add file → Upload files** арқылы архивтен шыққан файлдарды жүктеп, **Commit changes** басыңыз. `index.html` файлдың репозиторийдің түбінде тұрғанын тексеріңіз.
4. **Settings → Pages** бөлімінде **Deploy from a branch → main → /(root) → Save** таңдаңыз.
5. Жариялау аяқталған соң **Settings → Pages** бөліміндегі сілтемені ашыңыз. Мысалы, `https://USERNAME.github.io/aes-rsa-app/`.

## Телефонға орнату

- Android жүйесінде сілтемені Chrome арқылы ашыңыз. Қосымшадағы **Қосымшаны орнату** батырмасын немесе Chrome мәзіріндегі **Қолданбаны орнату** тармағын басыңыз.
- iPhone жүйесінде сілтемені Safari арқылы ашып, **Бөлісу → Басты экранға қосу** тармағын таңдаңыз.
- Алғашқы жүктеу аяқталған соң қосымша интернетсіз ашыла алады.

## Оқу моделі

AES + RSA үлгісі таңдалған әліпбидің әріптерін үлкен әріпке келтіреді және бос орындарды өткізіп жібереді. Кері шифрлау үшін бастапқыда қолданылған кілт пен әліпбиді таңдаңыз. Вижинер әріп регистрін, бос орындар мен тыныс белгілерін сақтайды. Жергілікті көмекші алдын ала жазылған анықтамаларды көрсетеді.

Тұрақты есептегіш, сандық кілт және шағын RSA модулі бар бұл модель оқу тапсырмасына арналған. Құпия деректерді қорғауға қолданбаңыз.
